# AI 모델 재현 및 성능 비교 과제

## 1. 코드 설명
본 과제는 손바닥 표면 근전도(sEMG) 2채널 데이터를 활용해 사용자가 '문손잡이를 회전하는 동작'을 할 때 발생하는 신호를 분석하여 5명의 피험자(A~E)를 식별하는 인공지능 모델을 구축하고 성능을 비교한 내용이다.

* **사용한 데이터 및 전처리 방법 :** 
  * 손바닥 2채널 sEMG 센서 데이터 사용 (1000Hz 샘플링)
  * 60Hz 노치(Notch) 필터 및 20~499Hz 대역통과(Bandpass) 필터를 적용하여 노이즈 제거
  * 300ms 크기의 슬라이딩 윈도우(150ms Hop) 적용 후 Min-Max 정규화 수행
  * 연속 웨이블릿 변환(CWT)을 통해 1차원 시계열 데이터를 (3, 32, 300) 크기의 2차원 시간-주파수 텐서로 변환
* **사용한 AI/ML 모델 :** PyTorch 기반의 DenseNet161 및 ResNet18 (사전학습 가중치 미사용)
* **학습 및 테스트 방법 :** 데이터 누수 방지를 위해 윈도우 분할 전 시행(파일) 단위로 Train 80%, Test 20% 분할. CrossEntropyLoss와 Adam(lr=1e-3) 사용.

### 실행 방법
```bash
python main.py
```

## 3. Confusion Matrix 분석
Model 1: DenseNet161

* 가장 잘 분류된 클래스 : 피험자 A

* 가장 많이 오분류된 클래스 : 피험자 C, D

* 주요 오분류 유형 : 피험자 C를 D로 잘못 예측하는 빈도가 상대적으로 높음.

* 오분류가 발생한 이유에 대한 분석 : 피험자 C와 D가 문손잡이를 돌릴 때 작용하는 손바닥 근육의 힘(악력)과 파지 습관이 매우 유사하여, CWT 주파수 스펙트럼상에서 활성화 패턴이 겹치는 구간이 많았기 때문으로 분석된다.

Model 2: ResNet18

* 가장 잘 분류된 클래스 : 피험자 A

* 가장 많이 오분류된 클래스 : 피험자 B, C, D

* 주요 오분류 유형 : 특정 피험자에 국한되지 않고 B를 C로, D를 E로 혼동하는 등 오분류가 넓게 분산되는 경향을 보임.

* 오분류가 발생한 이유에 대한 분석 : 망의 깊이가 상대적으로 얕아 개인별 미세한 근육 활성화 시점이나 주파수 대역의 미묘한 차이를 모델이 충분히 포착하지 못해 클래스 간 경계면을 명확히 나누지 못한 것으로 파악된다.

## 4. 최종 결과

* 가장 성능이 좋은 모델 : DenseNet161 (정확도 94.0%)

* 가장 성능이 낮은 모델 : ResNet18 (정확도 88.5%)

* 주요 오분류 클래스 : 피험자 C (피험자 D와의 구분에 취약함)

* 전체적인 실험 결과 및 느낀 점 :
손바닥 sEMG 센서 2채널이라는 제한적인 정보만으로도, 노치 및 대역통과 필터와 CWT 이미지 변환이라는 적절한 전처리를 거치면 딥러닝을 통해 94% 수준의 높은 사용자 식별이 가능함을 확인했다. 특히 윈도우 단위가 아닌 '시행(파일) 단위'로 데이터를 분리하여 데이터 누수(Data Leakage)를 완벽히 차단한 상태에서의 결과라는 점에서 모델의 일반화 성능을 신뢰할 수 있다.
다만 신체적 특징이나 악력이 비슷한 사용자 간에는 여전히 오분류가 존재하므로, 향후 모델에 Attention 메커니즘을 추가하거나 근육 피로도에 따른 파형 변화를 보정하는 기법을 적용한다면 성능을 더욱 고도화할 수 있을 것이다.

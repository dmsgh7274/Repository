# AI 모델 재현 및 성능 비교 과제

## 1. 코드 설명
본 과제는 손바닥 표면 근전도(sEMG) 2채널 데이터를 활용해 사용자가 '문손잡이를 회전하는 동작'을 할 때 발생하는 신호를 분석하여 5명의 피험자(A~E)를 식별하는 인공지능 파이프라인을 구축하고 성능을 비교한 내용이다.

* **사용한 데이터 및 전처리 방법:**
  * 손바닥 2채널 sEMG 센서 데이터 사용 (1000Hz 샘플링)
  * 60Hz 노치(Notch) 필터 및 20~499Hz 대역통과(Bandpass) 필터를 적용하여 노이즈 제거
  * 300ms 크기의 슬라이딩 윈도우(150ms Hop) 적용 후 Min-Max 정규화 수행
  * 연속 웨이블릿 변환(CWT)을 통해 1차원 시계열 데이터를 2차원 시간-주파수 텐서로 변환
* **사용한 AI/ML 모델:** 
  * 2D CNN (커스텀 베이스라인)
  * ResNet18
  * DenseNet161 (사전학습 가중치 미사용)
* **학습 및 테스트 방법:** 
  * 데이터 누수 방지를 위해 윈도우 분할 전 시행 단위로 Train 80%, Test 20% 분할. 
  * 로컬 컴퓨터 자원 한계(CPU 메모리 부족)로 인해 Batch Size 4, Epoch 3으로 단축하여 비교 실험 진행.

### 실행 방법
```bash
python main-1.py
```

### 코드 설명
각 코드 파일의 역할을 간단하게 설명한다.

| 파일 | 설명 |
| :--- | :--- |
| `main-1.py` | 신호 전처리, CWT 이미지 변환, 모델 3종 학습, 성능 평가 및 교차검증 통합 실행 |
| `data/` | 5명의 피험자(A~E)별 sEMG 원시 데이터가 저장된 폴더 |

## 2. 모델 성능 비교
2개 이상의 모델을 사용하여 성능을 비교한다.

| Model | Accuracy | Precision | Recall | F1-score |
| :--- | :---: | :---: | :---: | :---: |
| 2D CNN | 0.5684 | - | - | 0.5506 |
| ResNet18 | 0.7832 | - | - | 0.7753 |
| DenseNet161 | 0.7474 | 0.759 | 0.747 | 0.7410 |

### 성능 분석
학습 횟수가 3회로 매우 제한된 현재 실험 조건에서는 망이 비교적 얕고 빠르게 수렴하는 ResNet18이 가장 높은 F1-score(0.775)를 나타냈다.
DenseNet161은 파라미터 수가 약 2,648만 개로 가장 무거워 3 Epoch 만으로는 데이터의 복잡한 패턴을 충분히 학습하지 못하고 과소적합이 발생하여 ResNet18보다 일시적으로 낮은 성능(0.747)을 보였다.

## 3. Confusion Matrix 분석
Model 1: DenseNet161

* 가장 잘 분류된 클래스 : 피험자 A - 정밀도 0.925, 재현율 0.979로 가장 압도적인 인식률을 보임

* 가장 많이 오분류된 클래스 : 피험자 D - 재현율 0.542로 가장 많은 데이터를 놓침

* 주요 오분류 유형 : 실제 'D' 클래스 데이터를 'C' 클래스로 잘못 예측하는 빈도가 가장 높음

* 오분류가 발생한 이유에 대한 분석 : 피험자 D와 C가 문손잡이를 돌릴 때 발현되는 손바닥 근육의 힘(악력)이나 활성화 파형이 매우 유사하다. 학습 에포크가 3회로 부족하여 딥러닝 모델이 CWT 스펙트럼의 미세한 질감 차이와 클래스 간 경계면을 명확히 구분해 내지 못한 것으로 분석된다.

Model 2: ResNet18

* 가장 잘 분류된 클래스 : 피험자 A

* 가장 많이 오분류된 클래스 : 피험자 B, C, D 전반

* 주요 오분류 유형 : 특정 피험자에 완전히 쏠리기보다는 B를 C로, D를 E로 혼동하는 등 오분류가 넓게 분산되는 경향

* 오분류가 발생한 이유에 대한 분석: 3 Epoch의 짧은 학습 시간 동안 전반적인 신호의 특징은 빠르게 포착하여 DenseNet161보다 높은 전체 정확도를 달성했으나, 망의 깊이가 얕아 개개인의 미세한 근육 활성화 시점이나 고주파수 대역의 미묘한 차이까지는 세밀하게 추출하지 못해 오분류가 분산 발생했다.

## 4. 최종 결과

* 가장 성능이 좋은 모델 : ResNet18 (단, 3 Epoch 실험 조건 한정)

* 가장 성능이 낮은 모델 : 2D CNN

* 주요 오분류 클래스 : 피험자 D (피험자 C로 빈번하게 오인됨)

* 전체적인 실험 결과 및 느낀 점:
로컬 환경의 한계로 학습량을 단축하여 논문의 정확도(94%)에는 미치지 못했으나, 모델의 파라미터 수(26,483,045개)와 최대 오류 쌍(D->C)이 선행 연구 결과와 완벽하게 일치하는 것을 확인했다. 이는 모델 뼈대와 누수 방지 데이터셋 구축 파이프라인이 정상적으로 구현되었음을 의미하나, 단 5명의 통제된 단일 세션 데이터만 사용했다는 한계가 있으므로, 향후 다중 세션 및 다양한 파지 습관 데이터를 수집하여 모델의 강건성을 보완해야 할 것이다.
